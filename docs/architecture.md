# 架构与功能边界

| 模块 | 职责 |
| --- | --- |
| `apps/web` | Next.js 静态页面及客户端交互；攻略随版本发布 |
| `apps/edge` | Pages Worker 同源 `/api/*`：认证、内容、互动、消息、通知和商城 |
| `packages/domain` | 地点目录、共享模型与校验 |
| `apps/api` | 独立 NestJS 地理 API、Prisma/PostGIS；当前不是 Pages 运行依赖 |

普通页面由 ASSETS 提供，`/api/*` 交给 Worker 的对应模块。生产站点不需要开发者电脑在线。

## 数据与认证

D1 保存用户、会话、验证码、帖子、评论、关系、消息、通知、商品及购买意向。地点收藏和行程保存在浏览器；帖子收藏属于账号社交数据，和地点收藏不同。

会话使用 HttpOnly Cookie，HTTPS 下启用 Secure；写入要求同源 Origin。公开资料不返回密码或私有邮箱。修改密码需要当前密码，并撤销既有会话。验证码发送取决于邮件配置。

资料页用 `/profiles/?id=...` 支持任意用户，静态演示资料地址仍兼容。

## 内容与互动

Guide 与 Moment 都关联目的地，支持草稿、提交、撤回和删除，公开编辑需重新审核。图文、视频、相册和直播预约共用内容模型，媒体主要保存链接。

评论支持回复、表情、图片链接及基础语音附件。通知覆盖帖子的评论和评论回复，过滤自互动、不可用内容与拉黑关系。私信及群聊使用 API 获取消息，尚无 WebSocket 实时通信集群。

拉黑限制关注、评论和消息；解除拉黑不自动恢复关注。管理员有内容审核和举报处理入口。商城记录购买意向，不扣款或保证库存预留；直播模块提供预约和外部直播间入口，不承担推流。

## 内容目录与后续方向

地点目录在 `packages/domain/src`；攻略、来源和专题索引在 `apps/web/src/lib`。日本地图同时支持逐日路线备选与主题地点筛选。新增内容需同步目录、搜索、关联文章和 sitemap。

后续优先完成邮件服务和真实用户闭环，再逐步建设媒体存储／转码、直播基础设施、支付、行程云同步、更多国家内容和界面国际化。这些属于后续方向，不作为已上线能力宣传。
