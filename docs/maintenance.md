# 仓库维护

保留源码、运行素材、迁移、测试、配置、依赖锁文件和当前文档。

- `node_modules` 是本地开发依赖，不提交 Git。
- `.next`、`out`、`dist`、`.turbo`、TypeScript 缓存、OpenAPI JSON、地图 Worker 和测试报告可重新生成，不提交 Git。
- `.wrangler/state` 可能包含本地数据库，普通清理不删除。
- `.env`、`.dev.vars`、数据库、真实账号信息和令牌不入库，只有示例配置入库。
- 调研、录音、网页快照、发布图卡、一次性报告和备份放在项目外的私有归档。
- 保留旧数据库迁移，它们仍用于创建新数据库和理解数据结构。
- 删除前检查调用方、框架入口、动态资源路径和测试，没有直接 import 不等于没有用途。

## 2026-11-03 整理

合并 GitHub 的日本动漫及景点地图更新，保留本地路线备选、个人中心、社区和伊朗攻略。删除未引用的 `packages/config` 占位包；旧执行计划由当前文档替代，历史保留在 Git。

MapLibre Worker 与旧 OpenAPI JSON 改为自动生成；预览和测试统一使用锁定 Wrangler；临时攻略结构校验纳入正式测试。小红书成稿、源资料快照和恢复文件移入项目外私有归档。

`pnpm check:repo` 检查意外入库的生成文件、凭据特征、冲突标记和文档相对链接。删除后的可用性还需类型检查、测试、构建和浏览器验证，不能仅凭文件检查判断。
